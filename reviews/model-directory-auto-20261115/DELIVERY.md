# 模型目录自动读取

2026年11月15日，本地实现与隔离验收完成，未部署。

- 设置页填好服务地址与密钥后，停止输入600毫秒自动读取目录；无需先保存或选择模型。结果同时供模型标识及视觉模型输入选择，保留手动填写与刷新重试。
- 读取仅预览草稿，不保存密钥、不启用模型、不创建生成任务。更换地址、密钥、用途或移除密钥时取消旧请求并隔离结果，保留其他输入；选择模型后仍须保存配置。
- 服务端复用原有目录读取与地址校验，要求管理员权限；已保存密钥仅允许同源复用，目录地址必须与服务同源。沿用公开安全地址、解析后地址绑定、超时、响应大小限制和禁止携密钥重定向的约束。
- 视频继续使用显式目录地址；服务商未提供兼容目录时支持手动填写，不推断目录中的模型能力。保持既定深色样式，无新增依赖或数据库迁移。

最终验证：类型、规范、格式检查通过；156个文件2398项单元／集成测试全部通过。模型设置桌面9项、手机9项，共18项浏览器验收通过，无失败、跳过或重试；网页生产构建通过，两张自动目录截图已检查。测试断言实际保存配置、密钥加密与无生成任务，并覆盖快速改址、迟到响应、用途切换、目录失败重试及已保存密钥的站点限制。

证据为本机隔离目录：`platform/var/quality/run-XAP86q`（质量检查）与 `platform/var/e2e/run-UfpR1a`（浏览器验收）。首次浏览器启动受系统沙箱限制，使用所需本机测试权限后通过，环境启动失败不计为功能失败。此前12项浏览器试跑及24项定向单元测试不与最终数字相加。
