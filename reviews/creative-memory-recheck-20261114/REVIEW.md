# 创作记忆与产品资料复查

状态：已确认缺陷修复完成，交叉审查及最终回归通过。未在已列范围内发现剩余阻塞问题；不作“所有场景绝无缺陷”的保证。上一轮通过数字不代替本轮结论。

## 已确认问题

| 级别 | 问题与影响 | 修复方向 |
| --- | --- | --- |
| 高 | 相同需求的偏好权重随时间变化，可能绕过分析中／结果未知保护；工作流规划原本缺少相同保护，可能重复请求计费服务 | 比较稳定资料身份与内容，忽略动态权重和纯顺序差异；统一规划保护，并区分实际规划连接版本 |
| 高 | 产品和记忆的部分更新继承创建默认值，省略字段会清空资料或恢复启用 | 省略保留、显式空值清除，合并旧值后完整校验；保留并发版本检查 |
| 中 | 库内图片作为唯一原图配合蒙版时，规划就绪后报价仍查原始上传列表，错误拒绝继续 | 校验本人已确认、指纹匹配的素材快照；仍检查原图与蒙版对应关系，删除原图继续拒绝 |
| 中 | 分组模式保存的是临时关闭后的参数，刷新或切换入口丢失原记忆／产品图偏好 | 本地草稿保存原选择，实际分组请求继续强制关闭 |
| 中 | 版本冲突后只能退出编辑器或持续失败，无法保留输入完成修订 | 返回有权读取的最新记录，完整展示冲突；可载入新版，或合并未改字段后手动保存 |
| 中 | 数据库与选取逻辑的主题大小写规则不一致，允许同用途的矛盾记忆同时带入 | 读写采用同一比较；旧重复确定性择一引用，不删除记录 |
| 低 | 非创建者将共享产品转私有，旧流程直到末尾才报不存在并回滚 | 提前明确拒绝，保持共享编辑和私有访问边界 |

冲突恢复中还复查了同分钟不同秒的日期精度，避免合并后把用户修改静默改回服务器值。全部复现和回归均使用隔离数据库与合成资料。

## 审查范围

- 记忆类型转换、更新、暂停、重新确认、期限和衰减；个人、空间及接口权限。
- 产品可见性、关联品牌、参考图、回收恢复、部分更新和多人冲突。
- 单项创作、分组限制、草稿恢复、规划输入、报价、执行和未知结果恢复。
- 原生及工作流规划的请求去重、连接变更、来源快照和期限检查。
- 新界面桌面／手机、中文／英文／阿文、深色风格和账户缓存隔离。

既有不支持范围保持明确：分组套图、独立工具及整套详情页不接入新资料关联。没有新增真实收费调用、没有操作正式数据库、媒体或远端工作流。

## 迁移与兼容

追加第0041号迁移，只为创作方案记录规划连接版本。原生文本连接沿用既有配置版本；工作流连接保存带密钥的摘要，不存明文凭据。记录实际规划连接，避免仅按媒体模型识别而误挡明确更换连接后的新请求。

新记录按实际连接版本去重。历史非原生记录没有可证明的规划连接身份，保留原来的显式新请求行为，不伪造配置历史；旧原生记录仍沿用既有连接版本保护。历史已确认方案和任务快照不改写。迁移只在隔离库验收，将版本用于已有运行库前仍须在线备份、媒体校验和恢复检查。
