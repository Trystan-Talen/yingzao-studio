# 阶段四：fal 扩展适配自评

结论：六操作协议实现与独立契约测试通过，可以进入根集成；不宣称付费联调或原平台行为等效。

## 本次自查与修正

- 从官方模型 schema 下载七份原始 JSON，记录来源、时间和 SHA-256，避免凭 SDK 示例推测参数。
- 识别视频编辑返回单视频而图片分层返回数组的差别，与 worker 作者约定 `outputKind:'layers'`，不绕过现有普通操作的单产物约束。
- Kling “参考编辑”不能声称逐镜头精确复刻；时长、分辨率及保留音轨等参数按真实协议约束，已向根发送界面修订要求。
- 视频时长、尺寸及帧率不能只依赖任务选项，增加实际 ffprobe 探测；损坏视频在外呼之前失败。
- 图片参考验证 MIME、大小、最小尺寸、比例；提示词预留引用说明空间，并在最终拼接后再次检查长度。
- 安全检查必须开启；层安全标记缺失、数量不一致或命中不能记成功。图片数组限定 1–10，保留原始顺序，不编造语义标签。
- 检查提交返回地址，限制服务主机和 HTTPS；提交成功但响应不完整必须 ambiguous，不可当作普通失败后自动重提。
- 取消响应只是取消申请；轮询仍由 worker 确认终态。
- 分层 PNG 不等于可编辑文字或完整 PSD；翻译口播不等于图片文字翻译；去字幕协议证据不足，保留未就绪。
- 计费源视频实际秒数与 options.duration 不一致的风险已提示根修正；生成帧数与输出实际时长分别处理。
