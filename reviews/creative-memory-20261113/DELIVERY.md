# 创作记忆与产品资料交付

日期：2026年11月13日。状态：本地实现、审查及已列范围验收完成；真实模型效果与正式运行部署未纳入本轮。

后续复查发现并修复了首次验收未覆盖的缺陷；当前结论见[复查记录](../creative-memory-recheck-20261114/REVIEW.md)。下文保留当时范围与证据。

## 结论与设计

长期复用方向成立，但个人背景、创作偏好和产品事实不能混成同一种记忆。项目原有品牌库，本轮沿用其权限和引用流程，新增个人创作记忆与产品库；不自动从聊天推断用户画像，不增加收费记忆提炼。设计先于实现，见[方案](PLAN.md)。

| 信息 | 本轮规则 |
| --- | --- |
| 长期背景 | 自愿保存、同主题编辑替换、版本检查；不自动衰减 |
| 创作偏好 | 默认90天半衰，低于四分之一停止自动采用；阅读不刷新时间，可重新确认 |
| 临时要求 | 默认留在本次任务；保存为记忆时必须指定未来截止时间，到期停用 |
| 品牌与产品 | 品牌沿用现有库；产品支持事实、禁用表述、参考图、品牌关联、有效期、私有／共享和回收恢复 |

记忆按本人、当前空间和图片／视频用途筛选，最多8条、主题与正文合计6000字；优先有效临时要求、偏好、背景，同主题优先当前用途。筛选发生在服务端，个人记忆不进入商品事实通道。当前明确要求优先，资料冲突交给规划澄清；产品参考图需单独勾选。

## 使用与闭环

1. 「设置 → 创作记忆」维护、停用、重新确认和删除记忆。「产品库」维护可复用产品，可关联已有品牌。
2. 图片／视频单项创作的「更多创作设置 → 更多偏好」选择产品、产品参考图及是否使用记忆；保存本次要求需先核对、编辑和确认。
3. 整理需求后，在「本次采用的资料」核对实际内容、版本和期限。补答和执行沿用原快照；资料修改后，新方案读取新版。
4. 沿现有报价、确认、生成、保存及下载完成任务。到期或衰减失效的旧资料不能生成新报价，已报价任务仍使用原快照。

个人原始记忆及包含个人记忆的方案来源快照仅本人登录会话可读，开放接口不能借用个人记忆。采用的信息可能体现在协作成员可见的创作摘要、提示和作品中。删除或停用只影响后续引用，不抹除历史已确认方案。界面保留既定深色主风格。

## 审查修复与证据

- 补齐私有品牌经共享产品的隔离、失效素材与回收恢复校验、并发版本冲突；回收产品可先修复关联再恢复。
- 修复账户切换缓存隔离：同一空间切换用户、会话过期和迟到响应均不能闪现前一账户的记忆或私有产品。先复现失败，再通过组件及真实浏览器回归。
- 补齐准备请求字段传递、来源快照加载失败拦截、产品参考图显式选择及编辑重试保留草稿；已确认方案不被后续资料修改静默改变。
- 分组旧流程会在规划后拼入模块原文，可能绕过新产品约束。本轮明确禁止分组套图与新知识上下文组合；界面要求主动取消产品关联，关闭记忆并保留切回单张时的偏好。旧分组创作仍通过实际三张产物验收。
- 原生规划与 Dify（工作流编排平台）合同、提示及可导入包已同步。个人背景不能被当作商品证据，原始资料不在执行阶段再次拼入提示。

失败与回归保留在[证据目录](evidence/)，包括权限边界、回收恢复、账户缓存和分组限制的先失败后通过报告。桌面[记忆管理](evidence/desktop-memory.png)、[产品管理](evidence/desktop-products.png)、[确认来源](evidence/desktop-confirmation.png)及[手机记忆管理](evidence/mobile-memory.png)均为隔离合成资料。

## 验证范围

全量149个测试文件、2308／2308单元／集成检查通过，零失败、零跳过；末尾仅补两条界面译文，已另经语言、类型、规范、格式和生产构建复核。[最终检查汇总](evidence/checks.json)及[逐文件测试结果](evidence/unit-final.json)可追溯。379份产品源码、迁移和工作流文件在交付核对时与最终摘要一致。

- 浏览器基线86／86，覆盖桌面／手机创作、规划补答、登录恢复、设置与主题；之后仅3份产品源码有变化，见[差异清单](evidence/baseline-to-final.json)。
- 分组限制、英阿语和跨账户隔离10／10；单项新资料完整链路4／4；最后两条译文补齐后语言专项4／4。重复用例不相加，不宣称最后源码单次全仓浏览器通过。
- 新链路实际完成资料创建、关联、确认、修改、旧方案稳定、新方案更新、模拟产物保存与下载；下载与接口、磁盘和数据库摘要一致。并发编辑冲突保留草稿，记忆关闭和暂停生效。
- 类型、规范、格式、网页／服务端／执行器生产构建及隔离启动通过。生产运行检查覆盖空库注册、安全会话、服务端与执行器并发迁移，测试结束清理临时数据库。

浏览器使用本机 Chrome（谷歌浏览器）的桌面／手机模拟视口；本机下载的无头浏览器存在帧调度停滞，故切换执行环境，不以该环境故障推定产品缺陷。未做真实手机或其他浏览器内核验收。

## 明确边界

- 本轮支持单项图片与视频主创作。分组套图、独立工具和整套详情页不接受新资料关联；未实施逐模块知识规划、无限资料检索或向量数据库。
- 仅验证本机模拟、合同和工程行为，没有新增真实收费模型调用，因此不宣称真实模型对偏好或禁用表述的遵循效果已验证。
- 远端旧版 Dify（工作流编排平台）需要重新导入更新包，本轮没有修改远端服务。
- 第0040号数据库迁移为追加新表；没有迁移正式运行库、修改正式媒体、重启正式服务或发布。将源码用于既有运行库前，仍须在线备份、关联媒体校验及恢复检查。
- 本地目录没有版本库元数据，无法创建开发分支；未推送或合并。历史商业能力未验项继续以[功能台账](../takeover/scope-ledger.json)为准。
