# 前端重构参考与采用方式

调研日期：2026-10-30。以下来源为官方产品文档；查看了 Krea（创作工具）和 Midjourney（图像平台）的官方界面示意，未登录、未提交生成请求。采用方案是本项目的设计判断，不等于竞品实测结论。

| 官方案例 | 已核实的界面模式 | 本项目采用方式 |
| --- | --- | --- |
| [Krea（创作工具）视频生成](https://www.krea.ai/docs/user-guide/features/video) | 提示词、模型和主要参数集中；历史会话独立；参数取决于模型能力。 | 输入区固定，常用参数直接可见；不支持的参数不可伪装成可用选项。 |
| [Runway（创作平台）导航](https://help.runwayml.com/hc/en-us/articles/24298206897043-Navigating-Runway)、[创作会话](https://help.runwayml.com/hc/en-us/articles/33545310653203-Generating-with-Sessions) | 会话组织相关生成，便于比较与修改；项目聚合会话和素材。 | 提交后保留创作上下文；结果与原输入成组；最近创作可直接续做。 |
| [Midjourney（图像平台）网页创作](https://docs.midjourney.com/hc/en-us/articles/33390732264589-Creating-on-Web) | 结果旁可查看提示词、参数与参考图；支持复用文本和图片；详情提供下载和后续创作入口。 | 结果直接支持预览、下载、继续创作；素材卡提供“作为参考”，生成素材可追溯原任务。 |
| [Linear（任务管理工具）筛选](https://linear.app/docs/filters)、[任务视图](https://linear.app/docs/default-team-pages) | 活跃任务与历史清楚区分；筛选反映到地址，打开链接恢复同一视图。 | 任务状态常驻可见；搜索直接可用；筛选、分页和选中任务在地址中保留；高级筛选渐进展开。 |

## 本轮设计规则

1. 首页让用户直接选择图片、视频或商品详情页，最近工作可以继续；管理能力放在次级导航。
2. 普通生成并列展示输入与结果；详情页采用“准备商品 → 确认每屏 → 生成与导出”步骤，不强行套入自由画布。
3. 每个主要状态回答“正在做什么、完成多少、接下来能做什么”；恢复原任务与重新生成明确区分。
4. 任务列表优先显示创作摘要、真实状态、产物和主操作；参数、条目错误与归档收纳在详情。
5. 项目和素材统一标题、搜索工具条、计数、网格与列表；空态提供对应下一步，筛选为空可一键清空。
6. 采用中性白与浅灰工作面、深墨文字、靛蓝主色；媒体占主要面积，颜色只承担选择和状态含义。
7. 选中状态、键盘焦点和移动端入口必须可见；筛选变化清空旧选择，避免批量动作误作用于已隐藏项目。

## 验收边界

- 用户能判断从哪里开始、提交什么、提交是否成功、结果在哪里以及失败后如何继续。
- 刷新与返回后恢复正确任务；从素材和项目进入时保持对应上下文。
- 以可预览、可下载的实际产物验收链路；模拟产物与真实模型效果分别记录。
- 当前模型未开放的参考图或规格不能因为界面重构被宣传为已支持。
