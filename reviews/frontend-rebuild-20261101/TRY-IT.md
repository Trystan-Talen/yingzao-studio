# 新界面试用路径

先使用 [隔离体验入口](http://localhost:53840/)，这里不消耗模型额度，并与原工作入口分别保存登录状态和浏览器草稿。

- 账号：`preview@example.local`
- 密码：`PreviewStudio2026!`
- 所有模型结果都是带标识的本机模拟。示例素材用于检查交互、保存与下载，不能用来判断模型生成质量。

| 路径 | 怎么操作 | 应该看到什么 |
|---|---|---|
| 图片创作 | 首页选择图片 → 写需求 → 可选参考图 → 生成 → 核对费用后提交 | 自动进入项目；进度更新；结果可放大、下载。刷新后仍是同一次任务。 |
| 视频创作 | 首页选择视频 → 写画面与镜头 → 确认参数和费用 → 提交 | 视频结果可播放、下载；返回项目后可继续查看。 |
| 商品详情页 | 写商品信息、选一张参考图 → 开始策划 → 逐屏修改与确认 → 确认整套报价 | 每屏独立显示状态；完成后可下载单屏或整套。默认六屏，整套含六张原图、拼接长图与清单。 |
| 接着上次做 | 创作台保存草稿 → 返回首页 → 点最近项目 | 回到原项目，保留创作需求。已生成的记录也能在任务中心找到。 |
| 素材与工具 | 素材库选择“作为参考”；工具页搜索“图片文字识别” | 素材带回创作；工具搜索只显示相关结果，没有结果时可以清空筛选。 |

原有数据与真实服务使用 [原工作入口](http://127.0.0.1:53810/)。是否已经切换新版，以 [交付记录](./DELIVERY.md) 的实际回执为准。

需要重新启动隔离体验时，在 `platform/`（应用目录）执行以下命令。它会建立新的体验数据库；旧体验目录仍保留，原工作入口的数据不受影响。

```sh
pnpm exec tsx scripts/preview-experience.ts --port 53840 --api-port 53841 --root var/frontend-rebuild-20261101
```
