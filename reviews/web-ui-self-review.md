## 自评中修正的重要问题

1. 初开项目 revision=0 被严格 Zod 解析导致崩溃：仅 documentId + 正修订号时提供版本参数，表单构造采用安全解析，未填完整参数内联阻止提交，不在渲染时抛出。
2. 工作空间切换查询闭包竞态：查询键和请求都捕获同一 workspace ID，传入 AbortSignal；切换/退出先取消并清缓存。画布逐 ID 加载也显式绑定 workspace。
3. 网络失败重复点击可能生成新幂等键：报价保留快照及同一 UUID，失败重试保持请求身份，报价过期才重新估价。
4. 工具草稿被默认图片生成表单误解：在工作台提供原工具恢复入口，主工具及进阶工具读取完整参数、源素材、参考、遮罩。
5. 品牌/人物编辑只从首 100 个素材筛选会丢引用：改为逐引用 ID 读取，读取失败关闭编辑并明确报错，避免保存不完整引用。
6. 生成二次确认偏好与实际行为不一致：开启时显示报价确认；关闭时点击生成仍先服务端报价再提交、显示额度与服务商费用影响，始终经过预算约束。
7. 默认页面滚动延续导致新页面标题不在视口：路由路径变化恢复页面顶部；低高度侧栏改为导航独立滚动。

## 诚实边界

- OpenAI/fal/Flyelep 当前没有实际密钥，AI 输出质量/供应商端执行尚未做真人付费联调。此项不以本机图片处理成功替代。
- Stripe、第三方身份、短信、认证/发票等服务依赖真实配置。支付返回 success 查询参数只显示待核实提示，订单是否支付仍以服务端 webhook 状态为准。
- 原站未有公开可调用服务证明的 AI 洗图/部分视频功能，不伪造可用；UI 保留能力入口并按能力列表解释。
- 自动化文件上传受 Chrome 扩展“Allow access to file URLs”未启用限制；未修改浏览器权限。应用上传接口/常规文件选择保留，UI验收使用根代理导入的原创演示资产。后续真实粘贴上传另行记录，不将文件选择自动化限制等同于应用接口不可用。
- 本文暂不把未执行的所有资金/权限/外部模型路径标为“已实测”。最终整体测试及服务配置说明见根代理验收报告。

## Google 与邮件 UI 收口（2026-10-14）

- `GoogleAccount.tsx` 将登录入口与 `status.available` 绑定；设置读取真实 `linked` / `identity`，且只给 `hasLocalPassword` 账户关联/解除按钮。关联和解除均要求即时本地密码，密码只保留在当前表单状态，关闭后清空。Google-only账户明确不能解除唯一登录方式。服务端给出的授权地址只允许HTTPS的accounts.google.com，不接收任意跳转URL。
