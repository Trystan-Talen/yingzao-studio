# 本机试用路径

当前新版隔离预览：[打开创意平台](http://localhost:53850/)。仅本机模拟，不消耗真实模型额度。与原工作入口的账户、项目和媒体分开。

预览账号：`preview@example.local`；预览密码：`PreviewStudio2026!`。仅为这个可丢弃的本机演示账户。

1. 首页直接输入一句创作需求，选择图片或视频、模型和当前支持的规格。点模型说明可查看参数来源；切换模型会主动重新核查。
2. 点击生成，核对需求、规格与额度，再确认提交。页面自动进入项目，显示进度和保存后的作品。
3. 刷新页面，检查项目与产物仍在；图片可以作为参考或下载，视频可以播放和下载。
4. 返回首页，在“最近项目”继续未提交的草稿，在“生成记录”回访已有任务。
5. 商品详情页按“准备商品 → 确认方案 → 生成与导出”操作；可修改每屏描述并确认，完成后下载原图压缩包与长图。
6. 工具目录可以搜索普通、进阶及本机工具；设置中可切换明暗主题。

所有预览产物都有本机模拟标记。它用于测试操作链路，不能据此判断真实模型效果。

开发者重启隔离预览：先检查53850和53851端口是否被占用，再从 `platform/` 执行 `node --import tsx var/creative-integration-20261101/preview.ts --port 53850 --api-port 53851 --root var/creative-integration-20261101`。每次启动创建新演示数据库，旧演示记录仍保留在私有目录。没有配置电脑重启后自动运行。
