# 原生图片与视频编排交付

日期：2026年11月11日。代码、隔离合同测试及本机运行入口已完成；**星云引力真实模型调用与成品质量尚未验收**。本轮没有使用真实模型额度，不能沿用旧工作流的成功结论。

## 实现

- 保留现有深色界面、导航和组件风格，在「设置 → 模型配置」增加文本、图片、视频三个连接。支持地址、协议、模型标识、密钥、目录刷新、手动模型、启停与删除密钥。默认服务为星云引力；目录访问成功与生成验证分开显示。
- 密钥在服务端加密保存，只回传提示；管理权限按空间检查。请求限制地址、重定向、大小和超时，错误不回显凭据。追加第0032和0033号迁移，没有重写旧迁移。
- 图片：文本理解与最少追问 → 结构及事实来源校验 → 用户确认 → 图片生成与原件保存。
- 视频：文本分别规划首帧和动作 → 用户确认 → 图片生成首帧并保存 → 视频提交 → 持久任务查询 → 下载、解码、规格检查和保存。无需 Dify（工作流平台）。
- 冻结方案与配置版本。配置改变时明确重新检查，不自动重复付费。积分不足在文字调用前拦截；提交时仍原子核验。相同输入、配置及重试来源的首帧可复用；未知提交保留待核对，禁止盲目重发。
- 当前每次一张图片或一段视频、最多四张图片参考；视频为5秒／10秒、720p（高清）、单首帧，不提供尾帧、字幕叠加或音轨生成。视频最终尺寸容差2像素、时长容差0.5秒；不符时保留原件及远程编号，不标成功。
- 内部额度：图片8积分；视频每秒5积分另加8首帧积分，5秒为33积分；符合复用条件的重试为25积分。该额度不是服务商人民币报价，文本调用也可能由中转站计费。

## 使用与边界

双击根目录 `启动真实生成.command`（真实模式启动器），首次注册，在设置中填写星云引力的实际模型及密钥；准备本地平台额度后开始创作。完整配置与额度命令见 [应用说明](../../platform/README.md#本机真实生成入口)。原 `启动映造.command`（演示启动器）保持原行为。新入口没有自动创建账号、赠送积分或提交生成任务；原演示库、其他目录中的运行实例与私有媒体未改。

当前文本规划读取用户文字、已提取资料和参考图标识，没有把参考图像素交给文本模型；实际参考图交给图片模型。商品外观保持、复杂运动、视觉质量和模型对参数的真实支持仍需验收。图片按目标协议传入尺寸并检查解码，未将所有图片返回尺寸做逐项硬性验收。更强模型或移除工作流平台本身不能证明质量提升。

星云引力页面本次无法读取有效公开文档，尚未确认该账户实际模型目录与权限。适配依据为 [OpenAI（开放人工智能）结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat)、[图片生成协议](https://developers.openai.com/api/reference/resources/images/methods/generate)、[图片编辑协议](https://developers.openai.com/api/reference/resources/images/methods/edit)，以及火山引擎的[图像生成](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)、[视频提交](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)和[视频查询](https://docs.volcengine.com/docs/ark/get-video-generation-task-api?lang=zh)。兼容协议不等于已验证中转站实现。

下一步真实验收需要用户在页面保存凭据，并明确授权本轮模型消费预算；本仓库约定“外部凭据不代表预算授权”。未推送、合并或修改任何云端工作流。
