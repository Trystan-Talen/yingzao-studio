# 当前真实链路与全部提示词

核对日期：2026年11月13日。范围是当前配置星云引力的项目内原生图片／视频创作链路，包括参考复刻、精确换背景、首帧复用与受控运镜；不把旧外部工作流、演示模拟或其它专用工具当成本链路。此次仅只读源码、已有方案和当前确认偏好，没有调用模型、没有修改产品流程或界面。

**上一张图是简化主干，不是完全准确的逐节点实现。** 真实差异如下：

| 情形 | 当前实际行为 |
| --- | --- |
| 普通生图／生视频 | 通常只有一次文本规划；不会统一先做视觉预分析。文字模型拿到素材编号、名称、实测尺寸等，不直接看像素；实际图片交给后续图片／视频模型 |
| 参考复刻 | 一次视觉分析在前，一次文本规划在后；多张视频抽帧放在同一次视觉请求中 |
| 精确换背景 | 先文本规划，再在方案有效、需要模型蒙版且配置视觉模型时做一次背景视觉分析；观察直接用于蒙版提示词，不再追加一轮文字改稿 |
| 生成前确认 | 当前账号该偏好已开启。普通创作可关闭此设置，关闭后提交需求会继续准备、报价和生成；复刻始终强制确认，部分恢复和专用入口也会强制确认 |
| 视频中途确认 | 没有“首帧生成后再请用户确认视频”的步骤；确认覆盖整项任务，首帧保存并检查后继续提交视频模型 |
| 费用含义 | 方案确认前已经可能产生文字／视觉供应商费用。确认页面显示平台生成积分，供应商实际账单另计；不是供应商总费用的精确报价 |
| 自动检查 | 文件／尺寸／时长等检查是代码，不是视觉模型评分。检查清单供人工核对，没有“不满意自动重生成”的质量循环 |

真实主链路可按以下五行理解。每行到“执行”前遵守上面的确认设置；用户补充问题会主动触发新的准备请求，可能产生新规划费用。

```text
普通图片：用户需求 → 文本规划 → 确认设置／报价 → 图片生成 → 文件检查与保存 → 用户查看
精确换背景：用户需求 → 文本规划 → 可选背景视觉分析 → 确认设置／报价 → 模型蒙版 → 本机抠图填色 → 保存与查看
图片复刻：主体图＋参考作品 → 视觉分析 → 文本规划 → 用户确认 → 编辑自己的主体图 → 检查保存与查看
普通视频：用户需求 → 文本规划 → 确认设置／报价 → 复用原图或生成首帧 → 视频模型 → 检查保存与查看
视频复刻：主体图＋参考视频 → 本机抽帧 → 视觉分析 → 文本规划 → 用户确认 → 主体＋参考锚帧生成首帧 → 视频模型 → 检查保存与查看
```

限定本机静态平移是普通视频的独立分支：用户明确接受适用条件后，直接本机处理，不调用图片／视频模型。当前原生入口每次处理一张图片或一段视频，不是自动多候选择优。

背景视觉如果发现编辑范围不明确，会停止并要求澄清，清除可执行方案，不进入报价或蒙版生成。用户补充后主动重新准备，可能再次产生文字／视觉费用；这不是后台自动重试。

## 如何阅读提示词

- [完整提示词总文档](PROMPTS.md)：三份系统提示词全文、动态用户输入、图片／蒙版／首帧／视频编译原文和条件分支。固定文字直接抽取源码，没有润色；数值常量已按当前值展开。
- [六组已保存任务示例](ACTUAL-SAMPLES.md)：普通生图、两类自动背景、两类图片复刻，以及仅规划未执行的视频复刻。展示用户输入、模型生成的文字和保存后的最终提示词；不会把规划样例当作已发送的视频请求。
- [动态平台与用途指导](STRATEGY.md)：当前代码的完整策略文案枚举，另附180组选择条件的结构化数据。

系统提示词并非每张图都一样使用全部三份；按任务选择节点。图片和视频生成请求使用单一提示词字段，没有另一个隐藏的聊天系统提示词。动态最终提示词由本次用户需求和规划结果决定，所以不能用一段固定样文冒充所有任务。

## 节点索引

| 节点 | 是否请求外部模型 | 提示词组成 | 何时发生 |
| --- | --- | --- | --- |
| 素材验证、读取、视频抽帧 | 否 | 无提示词 | 准备期间 |
| 文字规划 | 是，文本 | 固定系统全文＋本次需求结构化输入＋动态平台／用途指导 | 确认生成前 |
| 参考复刻视觉分析 | 是，视觉 | 固定系统全文＋需求／帧时间信息＋主体与参考图像 | 文本规划前，确认生成前 |
| 背景视觉分析 | 是，视觉，按条件 | 固定系统全文＋编辑区／保护区／色值＋原图 | 文本规划后，确认生成前 |
| 普通图片生成／编辑 | 是，图片 | 规划结果＋约束＋按条件加入主体保留、商品事实和文字规则 | 正式提交生成后 |
| 图片复刻 | 是，图片 | 上述图片文本外，再包裹主体单图编辑约束；旧方案保留双图模板 | 正式提交生成后 |
| 背景蒙版生成 | 是，图片 | 专用蒙版全文＋允许编辑区＋保护区＋可选视觉观察；不用普通图像提示词 | 没有已保存蒙版且选择模型蒙版时 |
| 视频新首帧 | 是，图片 | 规划器首帧文本＋按条件主体保护段＋单张静帧要求；复刻再包裹双图职责模板 | 没有可复用首帧时 |
| 普通视频 | 是，视频 | 规划器视频文本＋首帧连续性固定段 | 首帧保存并检查后 |
| 受控平移／变焦视频 | 是，视频 | 服务端二维运动模板替换规划器视频文本＋主体保护段；本机计算尾帧 | 已确认且满足受控模式条件时 |
| 视频复刻 | 是，视频 | 规划器原始视频文本＋复刻专用固定段 | 新首帧保存后 |
| 本机抠图、精确平移、尾段停稳 | 否 | 没有向生成模型发送的提示词；本机方案文字仅供记录 | 按已确认的分支执行 |
| 查询、下载、文件检查、保存、预览 | 否 | 无创作提示词 | 执行与交付期间 |
| 用户不满意／继续修改 | 不会自行触发 | 没有后台自动质量循环提示词；用户操作才发起新准备或本机调整 | 用户主动选择后 |

本机抠图会运行本地前景分割模型并求解边缘，但它接收图像与蒙版，不接收自然语言提示词，也不产生外部模型请求。表中的“否”指不请求外部模型，不代表完全没有本地模型计算。
