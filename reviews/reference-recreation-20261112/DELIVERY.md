# 自动蒙版与参考复刻验收

更新：2026年11月13日。本轮自动蒙版优化、图片／视频参考复刻功能及已实现范围的工程验收完成。三种新正式自动换背景产物通过本例检查，两种真实图片复刻通过本例；真实视频创建按用户要求暂停，不能宣布复刻视频成片或全部商业功能已验收。现有视觉风格保持。

## 实际完成

- 精确背景换色采用“视觉识别区域 → 图片模型生成区域蒙版 → 本机前景分割与细边求解 → 指定色合成”。主体保护区使用原图像素，杯柄孔和叶间背景独立处理，不重新绘制整个主体。
- 对外部背景连续、没有内部背景孔洞且保留表面存在柔焦边缘的场景，才启用柔边场景处理。香水黑布的伪洞、颗粒灰晕和硬接缝已修复；杯柄与叶片场景不使用这个分支。
- 新版能识别模型返回的黑／浅灰双峰区域蒙版；仍拒绝彩照、大面积渐变、透明和异常尺寸。该校验只判断编码，不宣称语义划分正确。旧方案和旧蒙版算法保持原行为。
- 原图、付费原蒙版、诊断基线、最终蒙版和合成原件均保存。中断恢复只复用已有素材；最后植物恢复未重新调用图片模型、未重复结算。
- 可选人工调整始终基于同一自动原件和原蒙版计算，避免重复修改累计染色。本轮通过的三张自动成品没有人工涂改蒙版。
- 参考复刻：上传自己的主体和参考作品，选择构图、光线、配色；视频再选择运镜、节奏和参考选段。先分析实际参考画面，再生成可确认方案。新图片策略只把自己的主体图交给图片模型编辑，减少参考商品形状混入。
- 视频参考按实际时间抽取有限帧并分析，不含音轨；自己的新场景首帧与已确认运镜再进入视频链路。已完成真实抽帧分析和隔离协议验证，没有新建真实视频。

原杯子、植物及香水失败原件、被拒绝的算法试验均保留。未采用人工蒙版、针对验收坐标的定点修图或未通过的颜色种子方案作为自动成果。
