# 自动蒙版与参考复刻

目标是减少商品变化和返工；“爆款复刻”实现为可核对的参考分析与风格迁移，不承诺传播效果。保持原有界面风格。当前真实视频创建按用户要求暂停，图片与视觉分析继续实测。

## 输入与执行

- 原创：文字需求和可选素材。复刻：文字需求、参考作品、自己的主体图，三者职责分开。
- 图片参考可选择构图、布光、背景配色；视频再增加镜头和节奏，并限定参考选段。
- 独立视觉模型读取实际图像。视频只分析带实际时间戳的有限采样帧，不把主体图当视频帧，不声称分析音轨。
- 文本模型把观察转成可执行方案；缺失关键条件时补充，明确方案和费用后生成。参考中的文字不作为执行指令。
- 新图片复刻策略先分析参考，再以自己的主体图进行编辑；旧已确认双图方案保持原策略。生成式编辑仍不能承诺逐像素保真。
- 视频复刻以自己的主体生成新场景首帧，再执行已确认运镜；参考视频不直接作为视频模型输入。当前只验证了真实分析与隔离执行协议，不能宣称真实复刻成片通过。

## 自动蒙版

精确换色先冻结颜色、编辑区域和保护区域。视觉分析帮助区分主体、孔洞、台面和阴影；图片模型给出语义蒙版，再结合原图做本机前景分割与细边求解。本机合成保证蒙版纯白区为指定颜色、纯黑区沿用原图，但蒙版是否选对区域仍必须独立验收。

保留原始蒙版、标准化基线、最终采用蒙版及处理参数；失败不能覆盖旧证据，恢复不能重复付费或静默改用新算法。现有人工蒙版只作为可选兜底，不用于训练、拼接或伪装本轮自动结果。

## 验收原则

1. 分开记录工程检查、模拟协议、真实服务响应和实际视觉质量。
2. 使用既有口红、香水以及新生成的杯子、植物参考；新参考是测试合成图，不冒充实物摄影。
3. 先冻结背景内区、主体保护区和边缘标准，再读候选。不因失败修改验收范围。
4. 检查主体部件比例、指定背景色、孔洞、细叶、接触阴影和整段外轮廓；内区通过不能替代边缘通过。
5. 有形变或残边就保留失败，修复通用机制后复测；不针对验收坐标定点涂改。
6. 配置与数据使用真实库在线备份及恢复校验；密钥、媒体、登录态和私有证据不提交。
