## 启动器的隔离边界

源码 `platform/scripts/dev.ts` 第 4–8 行表明：`pnpm dev:demo`（演示启动命令）开启演示模式后，强制改用 `var/demo.sqlite` 与 `var/demo-media`，并执行演示数据播种。因此该命令会忽略调用者提供的数据库与媒体路径，不能用于需要保全既有演示数据的隔离验收。

本轮浏览器基线应由主代理从一致性备份建立隔离副本，显式指定数据库、媒体目录、端口和媒体命令路径，直接启动 `node --import tsx src/server/main.ts`（接口服务命令）与 `node --import tsx src/worker/main.ts`（任务执行命令）。保留生产数据播种保护，不以改写现有库换取可用演示。

该工程基线证明当前代码可编译、测试并在临时生产环境启动，不能代替原站功能对账、真实浏览器业务验收或外部模型效果验证。
