# 两组生成对比样例

两品牌、两产品均为虚构设定；参考图是本项目原创矢量示意，不是实物照片，也不是模型生成效果。样例用于检查资料遵循、产品形态、品牌风格和交互闭环，不代表真实商品功效。

| 品牌与产品              | 视觉差异                               | 容易核对的要点                                                     |
| ----------------------- | -------------------------------------- | ------------------------------------------------------------------ |
| 雾屿／岩白随行杯450毫升 | 苔绿、岩白；自然侧光、安静留白         | 450毫升、右侧提环、两条弧线符号；不得编造保温或认证                |
| 跃粒／方糖便携音箱      | 活力橙、近黑、米白；几何色块、硬朗侧光 | 方形机身、顶部三个按键、右上米白提绳、三颗圆点；不得编造防水或续航 |

## 使用顺序

1. 在已导入样例的当前账号空间进入图片创作，选择其中一个品牌和对应产品，开启“带入产品参考图”。将个人记忆关闭，避免个人偏好干扰。
2. 使用下方对应提示词，选择相同模型、画幅、输出数量、质量；不要在两次对比中悄悄换素材、改规格或加入历史上下文。
3. 比较通用产品时，将同一张参考图、同样的任务提示、品牌描述、产品事实和限制完整提供给对方。仅提供任务提示会使资料输入不对等，不能据此判断生成能力。
4. 先比较关闭思考模式的结果；再单独进行思考开／关实验。将是否规划、实际模型、时间、文本调用次数／费用、图片费用分别记录。不要把平台积分等同于供应商现金费用。
5. 每次只改变一个条件。需要比较更改资料后的遵循能力时，可将杯容量统一改为480毫升、同时更新参考图与两侧资料，再开一轮；不要复用此前已冻结方案。

关闭思考模式减少文本规划调用；它不保证成图一定更快或质量相同。这里尚未执行收费模型生成，也没有真实模型效果结论。

## 可直接使用的图片任务

雾屿：

> 为雾屿岩白随行杯制作一张1:1商品主视觉。只出现一个杯子，完整展示杯盖、右侧提环和杯底，主体居中偏右；左上留出约三分之一干净空间。苔绿与岩白色调，柔和自然侧光，浅色石台和细微纸感背景。画面仅写“轻装，慢行”和“450毫升”，不要其他文案、价格、认证或装饰文字。保持参考图中的外形、颜色和两条弧线符号。

跃粒：

> 为跃粒方糖便携音箱制作一张1:1商品主视觉。只出现一个音箱，完整展示橙色机身、黑色格栅、顶部三个按键和右上米白提绳，主体居中偏右；左上留出约三分之一干净空间。橙黑米白配色，硬朗侧光，简洁几何台座。画面仅写“轻装，开声”和“6瓦”，不要其他文案、价格、认证或装饰文字。保持参考图中的外形、颜色和三颗圆点符号。

视频任务也保存在下述导入模块的 `videoPrompt`（视频提示词）字段中：均为5秒、16:9、缓慢侧移的单商品展示，避免用不同动作增加干扰。视频服务是否支持时长和参考方式，仍以所选模型实际能力为准。

## 每轮记录

| 检查项     | 记录方式                                                         |
| ---------- | ---------------------------------------------------------------- |
| 输入一致性 | 模型、画幅、数量、参考原图、任务提示、品牌／产品资料、记忆开关   |
| 产品事实   | 容量／功率是否正确；产品数量、形状、按键、提环／提绳是否正确     |
| 品牌表现   | 配色、光线、符号、文字语气是否遵循                               |
| 指令遵循   | 左上留白、主体完整、指定文字准确；是否编造价格、功能、认证       |
| 稳定性     | 每种模式至少保留同等数量的结果，不只选最好的一张                 |
| 成本和时间 | 实际规划／生成请求、失败与重试、供应商费用、平台积分、端到端耗时 |

## 导入约束

实现位于 [导入模块](../../platform/scripts/comparison-fixtures.ts)，导出 `comparisonFixtures`（样例资料）和 `importComparisonFixtures(core, actor, workspaceId)`（导入函数）。调用者必须显式提供已有业务服务、已确认用户和空间编号；模块不会自行读取环境配置、打开数据库、创建空间、加积分或调用模型。

默认只允许空间所有者导入明确命名“生成对比测试”的独立空间。用户明确要求当前空间时，可传入 `currentWorkspaceAuthorization`（当前空间授权），其中 `userId`（用户编号）和 `workspaceId`（空间编号）必须与实际调用目标一致；每次重跑都需要明确传参，所有者权限不变。首次审计会记录这次位置选择。修改已有运行数据之前，调用方必须完成在线备份、媒体校验和独立恢复检查。可以在恢复副本上准备独立实例；不要用演示种子覆盖原运行库。

两个品牌、两个产品、两份参考图和导入审计凭据在同一数据库事务中写入。品牌额度不足会完整回滚并清理准备媒体。品牌和产品默认仅自己可见；原图可从素材库下载后提供给另一产品。品牌仅设置封面，不额外带入产品图；创作时由用户显式开启产品参考图，避免重复提交同一图片。

重复导入读取首次审计凭据中的编号，保留用户改名和资料编辑，不重新创建或覆盖。若已删除某个样例，重跑明确失败，应由用户在回收站恢复；不会擅自复活已删除记录。两份矢量源图分别为 [随行杯](mist-isle-cup.svg)与[便携音箱](jumpgrain-speaker.svg)，导入时使用已有图片处理库转为1200×1200像素原图。
