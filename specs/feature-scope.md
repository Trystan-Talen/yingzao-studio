# 功能范围、验收规格与工具能力表

版本：1.0；日期：2026-10-13（America/Los_Angeles）。本文件是阶段 2 规格，不代表应用已经实现。项目根目录为本仓库根目录，初期数据库使用 SQLite。

## 1. 范围与证据规则

目标是重建已确认平台的业务能力，并重新设计布局、交互和视觉。使用新产品自己的品牌、组件、源码、样例素材和接口；原站公开代码只作调查材料。F01–F52 唯一沿用 `research/static-feature-matrix.md`，不得按新导航重排编号。

主要证据：

- `research/observed-features.md`：E05–E06 已登录创作、配置、队列、既有结果、画布、版本、设计方案与导出入口。
- `research/live-tools-brand.md`：14 工具实际表单、型号联动、品牌配额及当前参考图模型形态。
- `research/live-account-assets.md`：A01–A19 资产、账户、团队入口、套餐、账本、订单、发票与开放平台。
- `research/static-feature-matrix.md`、`static-feature-audit.md`：不可达角色/数据条件下的公开代码证据。
- `research/public-api-docs/manifest.json`：可选 Flyelep provider 的公开协议来源；不是新项目已经取得该服务权限或密钥的证明。

范围标记：

- **必做**：当前可见功能，以及支撑这些功能的实际业务。原站账号没有团队、订单或素材，不成为删掉团队、开票申请、生成结果处理的理由。
- **必做，规则重定**：功能有证据但原站后端规则未知；采用本规格明确设计，交付时标注与原站尚未实测等价的部分。
- **保留，不作当前强制验收**：F38 旧品牌模板/内容定时订阅及 F52 过期营销活动。当前没有正常可达入口或有效活动证据，不能冒充“全部已开放”。若后续取得实际可用证据，应扩展基线而非悄悄遗漏。

**品牌参考模型不是神经网络训练。** 当前要求是保存品牌名称、参考图片、使用范围和生成引用；没有训练任务、权重、训练完成率或模型效果保证。

## 2. 所有功能共同适用的验收合同

以下 G 规则自动适用于后续每个 F 项，每项局部验收不能替代这些横向要求。

### G01：真实持久化与数据归属

用户、会话、空间、成员、项目、消息、任务、素材元数据、收藏、画布与版本、品牌参考、偏好、账本、订单、发票申请、API Key 摘要、通知、工单及审计必须真实写入 SQLite。媒体原件写入受管理的文件存储，SQLite 保存标识、校验值、MIME、尺寸、时长、字节数、状态和相对对象键。不能只用内存数组、浏览器 localStorage 或页面假状态代替服务器保存。

验收：完成一次相应创建/更新后，刷新浏览器并重启 API/worker，数据和归属一致；取消未保存编辑不写业务记录；故障不能返回“保存成功”。测试数据与初始示例有来源标记，不能伪装用户的真实生成记录。

### G02：身份、空间与授权

Actor/WorkspaceContext 由服务端会话或 API Key 推导。任何资源读取、列表、统计、下载、修改、删除、任务订阅都验证空间与权限；客户端传来的 memberId、role、balance 不作为权限事实。

采用 `architecture.md` 已确定的 owner/admin/member/viewer 矩阵：owner独占团队解散/所有权转移；owner/admin可管理成员/预算、空间provider/API Key/订单，admin不能修改owner或全局部署密钥；member可创作/编辑本团队工作空间资源；viewer只读。团队协作资源与个人空间私有资源分开，个人资源不因加入团队自动共享；对外分享仍按链接授权。viewer是新产品明确增加的只读角色，不声称原站已具有。成员移除后立即丧失团队读取/下载/事件订阅权限，仍在执行的任务按提交时空间归属完成并结算，不能转入成员个人空间。

验收：两个用户/两个空间之间对每类资源都不能通过换 ID 越权；隐藏按钮只是 UI，服务端拒绝才算通过。管理员不能越权修改创建者；已撤销 Key 和会话不可继续访问。

### G03：输入与能力校验

客户端用来即时提示，服务端重复校验文件、必填字段、参数范围、引用归属、模型能力与组合输出数量。上传完成并通过元数据/原件校验后才可生成。上传中、处理失败、认证未通过的素材不能被当作 ready。

能力由版本化 `ModelCapability` 定义，至少含 task types、媒体类型/数量/大小/像素/时长、输出分辨率/比例/时长、批量上限、首尾帧/音频/人脸/字幕支持、取消与查询支持。原站型号仅记录对照关系；对用户展示实际配置的供应商与模型名。切换模型时清理不支持字段，展示参数调整说明，不静默提交错误值。

### G04：外部依赖和缺配置行为

每种能力必须由经验证的 provider adapter 或真实本地处理器执行。没有密钥、商户、认证服务或所需模型能力时，在提交前给出明确的“未配置/当前模型不支持”状态与配置入口；服务端返回结构化错误，不创建假成功结果、不插入虚构媒体、不扣费、不用倒计时冒充进度。

不得假定“配置一个生图 API”就支持视频、洗图、分层、字幕处理、训练等所有能力。Flyelep 公开文档当前不覆盖的独立能力须由其他适配器承接或列为待配置；不能猜测私有端点。外部接口失败要保留可追踪请求标识与经脱敏的错误；密钥不得进入前端、浏览器日志、SQLite明文导出或截图。

### G05：任务、幂等与恢复

统一任务服务支持 jobs、job_items、job_attempts、job_events；业务状态至少有 queued、running、succeeded、partial、failed、cancelled，并有需对账/状态不确定的 reconciliation_required 处理路径（字段命名与 `architecture.md` 一致）。SSE 是通知通道，断线不代表任务失败或取消。

验收：重复同一幂等请求只创建一次任务/预留一次算力；worker 重启以 leaseToken 防止旧 worker 回写；刷新后恢复同一任务；SSE 从事件游标续接；每个批量输入有稳定 item ID，不能仅用压缩成功输出的数组下标映射原图。结果晚到不串到其他会话/空间；重试可查询的外部任务应先查状态再决定是否重新提交。

### G06：计费、取消与未知结果

价格以服务端配置为准，在提交时保存版本和参数快照。先计算最大可收额度并原子预留，按确定成功的计费单元结算，释放剩余预留。失败、部分成功、取消、退款都产生不可变账本记录；同一供应商事件重复投递不会重复入账。免费额度单独记录消耗，不是价格设0后无限使用。

取消区分取消申请、供应商确认及最终结算。仅终止前端/SSE或请求超时，不能自动判取消成功/退还。供应商状态不确定时标记待核实并保留可说明的预留，后台对账或经审计人工调整解决。UI 解释状态和余额占用。

### G07：媒体与画布完整性

原件、预览、缩略图、导出是不同资产版本。编辑/导出不能把失效原件静默替换为低清预览。异步结果记录目标文档和起始 revision；若用户已修改、删除目标、回滚或切项目，结果进入 pending_applies，由用户应用/丢弃；不覆盖新编辑。

### G08：UI 可用性与真实结果

每个页面具备加载、空数据、无匹配、权限不足、缺配置、错误、重试状态；键盘可操作，可见焦点，表单错误对应字段，按钮有处理/禁用反馈。桌面是主要生产场景，窄屏可查看队列/资产/表单；复杂画布窄屏提供明确操作模式，不把工具挤成不可用控件。下载成功以取得可打开文件及检查内容为准，不能只凭按钮动画或弹窗关闭。

### G09：删除、审计与可追溯

新产品采用可恢复删除处理项目/素材/品牌/用户创建的内容；被在途任务或历史版本引用的原件不能立即物理删除。永久清理遵循保留策略且需明确确认。账户角色、算力、财务、密钥、分享和团队操作写审计。取消收藏只删除关系，不能删原始资产。

### G10：验收层级

交付矩阵分别记录：①业务实现；②适配器合同测试；③真实供应商联调；④端到端视觉/文件验收。测试适配器只在测试环境使用并明确命名，不进入正常产品模型列表。没有③时不得宣传对应模型真实生成已验；缺配置不是删除该功能的理由，也不是将测试结果替代真实交付的理由。

## 3. 外部依赖缩写

## 4. Canonical F01–F52 逐项要求与验收

### F01 创意首页与灵感分类 — 必做

**实现：** 图片/视频灵感目录、分类/行业/平台/主题筛选、搜索、分页、预览与详情。示例素材须原创、授权或用户导入；记录类型、来源、可复用配置和缩略图。首页入口按用户任务组织，避免照搬原站卡片布局。

**验收：** 新建管理员目录数据后重启仍可见；组合筛选只返回匹配项，清空恢复；无匹配与媒体缺失有不同状态；视频预览能播放/暂停，关闭预览停止音频；不能用原站用户资产作新产品示例。

**依赖：** MEDIA；静态目录不依赖模型，生成复用关联F02。

### F02 示例复用与收藏 — 必做

**实现：** 收藏案例/项目；复用复制允许公开的提示、比例、素材引用、模型能力映射到新草稿，保留来源关系，不修改原案例；不支持的模型配置提示替换。

**验收：** 双击收藏不重复，刷新保持；取消收藏不删项目；复用后改名/改参数不影响原案例；不可见资产无法借复用泄露；已下架案例保留收藏的不可用说明。

**依赖：** 无；后续生成按IMG/VID。

### F03 首次引导与默认偏好 — 必做

**实现：** 可跳过的首次引导、默认平台与创作语言、最近使用参数；偏好按用户与空间明确归属，界面语言独立于输出语言。

**验收：** 跳过/完成状态重登不重复弹；不同用户不共享；修改默认值仅影响新草稿，不能重写已有项目配置；保存失败不提示已保存。

**依赖：** 无。

### F04 电商图片生成 — 必做

**实现：** 详情图、产品套图、主副图、白底图、单图；产品描述/卖点、平台/语言、品牌/参考图、型号/通道、数量、比例/尺寸、分辨率、文字选项。套组支持主图、展示、卖点、场景、款式、细节、效果、参数、功能等模块的选择、素材关联与顺序；具体输出类型由实际provider能力限定。

**验收：** 单图与整套任务生成真实文件，输出尺寸/数量/顺序对应请求；白底任务结果按所选场景约束验收；类型切换自动校正数量范围且不丢未经确认的素材；批量部分失败能单项重试；无密钥按G04拒绝。

**依赖：** IMG、TEXT（需求解析/方案）、MEDIA。

### F05 营销物料与自由图片创作 — 必做

**实现：** 营销场景、物料类型、多尺寸组合、自定义提示、统一/随机风格；自由创作可从文字和参考素材起步。场景/物料配置为可管理数据，不硬编码单一活动模板。

**验收：** 一个营销需求配置两个物料尺寸，保存并生成各自结果；同一项目切换物料不重写已生成版本；自由创作无电商平台时可提交被provider支持的请求；动态配置变更不破坏旧任务快照。

**依赖：** IMG、TEXT、MEDIA。

### F06 视频生成 — 必做

**实现：** 主图视频、种草视频、品牌TVC、自由视频；全能参考/首尾帧、混合参考图片/视频/音频、文本、语言/字幕、型号、时长、清晰度、比例；有音轨与口播能力按provider显式配置。

**验收：** 真实视频可播放并核对时长/画幅/音轨；首帧/尾帧模式正确传对应文件，混合参考顺序稳定；不支持音频/人脸的型号清理旧字段并说明；切换型号自动收敛时长/分辨率，不套用全局最大值；缺VID不能以图片轮播冒充视频。

**依赖：** VID、MEDIA、可选TEXT/FACE。

### F07 多模态素材上传与 @ 引用 — 必做

**实现：** 拖拽/粘贴/文件选择、上传进度、删除/重试、元数据校验；图片/音视频/文档引用；@引用在编辑、存储、恢复与请求构造中保持稳定ID。文档只提取受支持文本，展示提取结果与错误。

**验收：** 上传中禁止生成；损坏文件、扩展名与实际MIME不符、超限被服务端拒绝；断网重试不重复入库；删除被引用素材给出影响提示；刷新后引用可解析；文档提取不把文内指令当系统指令。

**依赖：** MEDIA；可选TEXT用于结构理解。

### F08 AI 帮写、生成确认与报价 — 必做

**实现：** 基于当前需求/素材的帮写建议、换一批、选择应用；免费次数和收费规则；提交前参数与费用确认；用户可持久关闭/重新开启确认弹窗。

**验收：** 帮写结果基于输入而非固定样例；选建议只更新草稿，不自动生成；免费额度并发原子扣减；报价变化需重新确认；关闭确认仍受服务端预算/权限/能力校验，不能绕过计费。

**依赖：** TEXT；计费服务。

### F09 会话、多轮创作与设计方案 — 必做

**实现：** 新建/命名/删除/分页会话，保存用户与系统消息、配置快照、关联任务和结果；支持补充需求、选择设计方向、方案确认、继续生成、重新生成。设计方案结构涵盖图片内容分析、目标、风格、颜色、图像/文字/版式、场景和技术规范，可复制。

**验收：** 同一项目续聊继承明确的上下文，另起项目不串素材；确认设计方向与付费生成分离；已有图的方案由真实TEXT视觉/文本服务产出，分析不支持时明确说明；刷新可恢复消息与任务；删除会话不误删其他收藏/版本所需原件。

**依赖：** TEXT、IMG/VID。

### F10 队列、并发、取消与恢复 — 必做

**实现：** 全局任务中心，处理中/排队/完成/失败/待核实，个人与团队并发额度；任务详情、取消、重试、跳转项目、事件流恢复；保留供应商任务关联和每次尝试。

**验收：** 一次提交超出并发上限进入持久队列；重启后按租约安全恢复；两次相同请求不重复扣款；取消与完成同时发生只产生一个最终事实；连接断开后重开仍可取结果；管理员只看到有权任务信息。

**依赖：** provider查询/取消能力、后台worker；不支持取消时如实显示。

### F11 智能延展 — 必做

**实现：** 单张/批量原图、目标比例或明确尺寸，保留原图并生成新资产，沿用表1输入校验。

**验收：** 输出像素/比例正确且包含原主体；超限组合拒绝；批量结果对回稳定输入ID；不采用简单加纯色边框冒充AI延展。

**依赖：** IMG的outpaint/extend能力。

### F12 局部重绘 — 必做

**实现：** 原图、可选替换参考图、画笔/橡皮、画笔大小、遮罩清除/预览、修改提示；工具箱与画布入口使用同一服务。

**验收：** 缩放/旋转后的涂抹正确映射原像素；无有效遮罩不能收费提交；结果保留为新版本；处理期间编辑产生待应用结果；模型不支持mask时不可悄悄全图重画。

**依赖：** IMG的mask编辑，MEDIA。

### F13 放大与超清 — 必做

**实现：** 无损放大2×/4×/8×和轻度/标准/强力超清为独立工具配置；批量；受实际provider最大输出尺寸限制。

**验收：** 放大像素倍数正确，原件保留；超清真实调用增强能力；超过像素/内存限制在提交前拦截；不会把浏览器CSS放大或普通缩略图拉伸描述成AI超清；逐张失败单独显示。

### 工具配置必须处理的差异

1. **观察与产品决定分开。** 图片翻译现场只验证到单个语言选择器，多语言批量来自静态支持线索；新产品可清晰提供多选并受组合上限控制。图片复刻现场未见数量字段；不凭静态旧文案添加无限生成数量。
2. **型号能力依上下文区分。** 创意视频生成与视频复刻的相同展示型号可能有不同可用范围；capability键须含任务类型。已观察视频复刻Dance2.5为480/720P、4–30秒；Dance2.0为480/720/1080P/4K、4–15秒。新provider按实际协议配置，不仅按这些品牌字符串硬编码。
3. **原始媒体限制与输出限制不同。** 源视频最长/累计参考时长、输出时长、上传大小分别校验，不能合成一个duration字段。
4. **价格空态不等于免费。** 无素材导致原站显示0算力；新UI应显示“添加素材后估价”，避免误导。
5. **组合映射不猜测。** 外部接口若只返回成功URL且省略失败项，adapter必须取得item相关性或逐项提交，不能靠下标错误回填另一张商品图。
6. **provider契约不泛化。** 例如Flyelep公开协议OCR、改字和图层坐标格式不同；通常header传secretKey但余额查询在body；视频查询只有短路径、无独立OpenAPI的部分不能猜路由。AI洗图、视频后处理、人脸认证、品牌训练没有该公开协议的可调用端点证明，不能把它们算作该adapter已覆盖。详情见 `research/flyelep-public-api.md`。
7. **工具与画布共用服务。** 同一能力在工具箱/画布/API入口的校验、报价、任务记录、结果保存一致；画布另带revision与targetLayer元数据。
