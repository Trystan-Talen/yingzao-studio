# 独立接口额度账户

渠道 `web`（网页）、`api`（接口）由任务提交时认证类型决定，并冻结于报价、任务和条目。请求参数不能选择任务扣费渠道。报价、重试、请求幂等均须保持渠道一致；工作进程及取消、退款按冻结渠道操作，不从工作进程临时身份推导。

旧余额、来源、流水、在途任务与订单均迁移至网页，包含旧接口密钥创建的在途任务；接口账户初值为 0。原有来源失效、封存、恢复、预留及冲正算法在各自渠道内复用。密钥额度上限仍作为第二层限制。网页分配预算不隐式转入接口账户。

普通额度端点按认证渠道返回数据；网页会话访问接口账户管理须工作空间管理员权限，密钥不能访问管理员端点。接口订单仅允许额度包，创建时显式确认渠道；付款、充值、退款、风险冻结及人工对账均锁定订单渠道，兼容没有渠道元数据的历史付款但拒绝显式冲突。不把接口充值加入网页推荐奖励。

界面必须说明接口账户使用平台额度，无现金价值承诺。原站现金充值转算力价格、真实付款和真实供应商效果未验证。

验收：接口 0 初值、网页不能补接口余额；交叉报价/幂等/重试拒绝；独立预留/成功结算/取消释放/退款/失效；密钥预算叠加；管理员权限隔离；旧接口在途按网页结算；旧迁移校验和保持不变；支付用本地测试数据，不调用外部服务。
