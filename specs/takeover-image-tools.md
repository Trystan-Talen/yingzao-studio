# 新增图像工具：消除与模特替换

2026-10-16。来源：主代理本轮原站实际观察；具体页面证据由主代理补充。新增 F53、F54，保留旧 F01–F52，不把新增工具并入局部重绘的完成数字。

| 项目 | F53 魔法消除 | F54 模特替换 |
|---|---|---|
| 操作标识 | `image-erase`（图像消除） | `model-replace`（模特替换） |
| 目标 | 去掉蒙版中的物体，补全周边背景 | 把服装源图中的服装呈现在目标模特上，保持服装细节 |
| 输入 | 1 张原图、原尺寸有效蒙版；补充说明可选 | 1 张服装/人台原图、1 张目标模特图；命名的背景参考槽位和补充说明可选 |
| 限制 | 原图不超过10MiB（兆字节）、宽高各不超过8192、长短边比不超过5；本机统一图片面积暂限6400万像素 | 各角色只接受图片；原图和目标模特必选，背景独立校验并冻结；单次1个结果 |
| 产物 | 新图片；本地按原图尺寸、原蒙版合成，未涂画像素来自原图 | 新图片；原始三类输入角色和参数可追溯；不保证模型像素级服装一致性 |

与现有局部重绘区分：消除不允许替换参考，不要求用户描述新增内容，固定去物体/补背景意图；局部重绘继续允许用户指定替换内容。模特替换独立保存服装、目标人物和背景角色，不用商品替换的多参考笛卡尔组合。

适配方案：

- OpenAI（模型供应商）的图像编辑支持多输入与首图蒙版，可覆盖两项。目标模特为第2图、可选背景第3图；消除结果另由本机蒙版合成保护未编辑区域。[官方图像编辑协议](https://developers.openai.com/api/reference/resources/images/methods/edit)
- fal（模型供应商）的 Bria（消除模型）使用 `image_url`（原图地址）、`mask_url`（蒙版地址）、`mask_type=manual`（手绘蒙版）；转换为白色修改/黑色保留，不能直接传本机透明蒙版。[官方协议](https://fal.ai/models/fal-ai/bria/eraser/api)、[蒙版语义](https://docs.bria.ai/image-editing/editing)
- fal（模型供应商）的虚拟试衣有 `person_image_url`（目标人物）、`clothing_image_url`（服装源）、`preserve_pose`（保持姿态），没有背景图/自定义提示词字段；这两项在该模型下明确拒绝，用户可换 OpenAI（模型供应商）。[官方试衣协议](https://fal.ai/models/fal-ai/image-apps-v2/virtual-try-on/api)

验收：

1. 空蒙版、尺寸不匹配、超限图片、缺目标模特、跨空间背景在外部调用前拒绝；不消耗模型费用。
2. 消除请求使用正确蒙版方向；对非正方形、局部偏移、半透明边缘进行真实文件测试；原图未编辑像素与输出保持一致，输出尺寸与原图一致。
3. 模特替换三槽位顺序、独立背景字段、快照和恢复不串位；不支持字段明确拒绝。
4. 界面可绘画/擦除/清空/保存蒙版，能保存与重开两个新工具草稿，结果进入同一任务与资产链。
5. 合同和本机像素测试不代表真实模型效果。人物身份、服装细节、纹理、遮挡及消除自然度均标外部未验证；未获预算不执行付费调用。

差异：原站8192平方对应约6711万像素，略高于本机统一6400万像素上限。本轮明确展示本机限制，不把这一边界算作完全等价；扩容须统一媒体存储、画板及模型限制后另验。
