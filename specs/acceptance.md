# 验收计划

每项F编号实现位置与证据在最终coverage表记录；这里规定跨模块质量门槛。

## 真实业务闭环

1. 初始注册/已存在账户登录 → 个人空间 → 建项目 → 上传原创图片 → 保存会话与画布 →刷新恢复 → 导出真实PNG/JPG并核尺寸 → 收藏/筛选/回收/恢复。
2. 本地真实工具：多图拼接、裁剪、转码、视频裁剪等执行后入资产库，有真实尺寸、任务状态、导出字节。
3. 图像/视频生成：未配置服务明确不能执行且不预占额度；配置可用协议后走真实provider，保留远端ID，成功输出须文件验证。fixture仅用于自动化契约测试。
4. 团队：两个用户/两个空间，跨空间资源/关联外键/下载拒绝，viewer写拒绝，移除成员旧会话立即失权；成员预算独立可验证。
5. 额度：同幂等键同payload只建一次；变更payload冲突；不足拒绝；排队取消归还；失败归还；部分成功按item结算；已提交未知保留核对。
6. 画布：拖动/文字/样式/层级/撤销、缩放后坐标保存一致；版本冲突保留草稿；异步结果不覆盖新编辑；历史恢复产生新revision；原图而非thumbnail导出。
7. API key：创建仅显示一次明文，数据库摘要；撤销立即无效；scope/workspace/预算生效；不得读取其他账户secret。
8. 外部商业能力：订单/发票/认证等待真实adapter状态，未配置显示不能执行，不显示已付款/已开票/已验证。开发测试额度无现金价值。

## 自动验证

pnpm typecheck / lint / test / build 独立运行。Vitest使用临时SQLite与测试storage，真实SQL事务；Fastify inject测路由、Origin、会话、权限、资产。租约恢复与billing敏感功能有故障注入。契约fixtures标来源/语义，不夸大成真实模型测试。

迁移从空库建立与再次执行幂等；SQL外键和完整性检查。使用SQLite在线backup与媒体清单复制，恢复临时目录后查完整性及文件hash。

## 浏览器与视觉

所有交互验证用CUA：1440桌面、390窄屏。首页、创作、工具、项目、素材、品牌、团队、设置与开发者均实际打开。关键表单创建/更新后刷新验证。检查加载/空/错误/未配置/权限不足，模态focus/Escape，手机导航与表格滚动，无控制台报错/图片破损。

保留关键页面截图与验收日志；发现问题修复后只回归受影响路径，不为次数而重复。最终交付说明对每个外部adapter区分implemented/contract-tested/live-verified/unconfigured。
