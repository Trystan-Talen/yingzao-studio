# 本机精细抠图辅助器

此目录不包含模型或安装环境。TypeScript（类型脚本）服务继续负责任务、权限、积分与检查点；本机辅助器只执行已冻结的离线图像计算。

`pnpm build`（构建命令）校验三个脚本的固定摘要，并复制到 `dist/runtime/local-matting/`（运行目录）。生产部署必须包含这些文件。模型与隔离 Python（解释器）环境单独安装，不能在请求期间下载或安装。

安装目录的 `installation.json`（安装清单）仅含四个字段：

```json
{
  "version": 1,
  "pythonPath": "/absolute/venv/bin/python",
  "runtimePath": "/absolute/deps/node_modules/onnxruntime-node",
  "modelPath": "/absolute/BiRefNet-general-bb_swin_v1_tiny-epoch_232.onnx"
}
```

路径必须为绝对路径；解释器必须指向隔离环境入口，不能替换为其符号链接的真实目标。模型为官方 BiRefNet_lite（轻量模型）1024 版本，224,005,088 字节；摘要与完整依赖版本以 `src/server/providers/local-matting-version.ts`（固定版本文件）为准。复用已核验的本机文件即可，无需重复下载。最终求解保持原图分辨率，不能将轻量模型称为高分辨率模型。

服务端与执行器配置 `LOCAL_MATTING_INSTALLATION_DIR`（安装目录）和 `LOCAL_MATTING_WORK_DIR`（临时工作目录）；仅测试或专门部署使用 `LOCAL_MATTING_HELPER_DIR`（辅助器目录覆盖）。不把这些路径传入浏览器。缺少环境、版本错误或原图超限，会在付费蒙版调用前停止。

当前运行隔离针对 macOS（苹果系统）：子进程禁止网络（包括遥测外发），环境变量使用白名单并设置禁遥测标志；同一进程排队并使用文件锁跨进程串行。父进程每 250 毫秒检查整组驻留内存、取消和执行权，单任务上限为 16 GiB、10 分钟。模型不读取用户凭据，源图通过私有临时文件传入，不放进环境变量。

种子浮点数据仅存在本机计算目录，完成或失败后删除。持久保存付费原始蒙版、归一化基线、最终 8 位编辑蒙版和合成 PNG（无损图片）。后两者必须成对事务保存；恢复完整成对检查点直接复用原件，不再运行模型。只有付费原件完整时才可显式重做失败的本机计算，外部调用次数为零。人工修订绑定不可变根基线，未改蒙版时返回原合成文件字节，不重新估计前景颜色。

`continuous-soft-exterior-v1`（连续柔焦外背景）仅允许由服务端视觉分析确认前提后冻结；缺少字段保持默认算法。它是有条件的场景边界估计，不宣称真实透明度，也不替代最终视觉验收。
