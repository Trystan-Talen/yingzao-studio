# 本地密码设置与恢复

此流程按本轮明确安全设计实现，原站未观察到对应密码入口，不能据此宣称语义等价。

默认关闭。启用前备份数据库，并同时配置已授权的加密邮件传输服务与固定公共源地址，再显式设置 `PASSWORD_RECOVERY_ENABLED=true`（密码恢复启用配置）。仅填写邮件账号不会自动开启；开启而未配置有效发信服务时启动会失败。不要在未经授权的验证中开启真实发信。

登录页“忘记密码”用于已有本地密码的账户。仅通过谷歌创建的账户须先用既有方式登录，在“设置 → 账户安全 → 本地密码”申请设置邮件；邮件绑定发起会话，须在同一浏览器打开。邮件链接 30 分钟有效，只有提交合法新密码才消费；成功后全部网页会话退出。谷歌关联保留；已有接口密钥是独立凭据，应在密钥管理页审查和撤销。

申请恢复始终返回统一文案，不透露邮箱是否存在；接口受持久化来源/邮箱限流约束。账号全局恢复数据独立于工作空间邮件队列，不向空间管理员公开。邮件采用持久加密队列；临时拒绝有界重试，接受状态不明时不盲目重发，用户可稍后重新申请链接。关闭功能后停止领取旧恢复邮件。

追加迁移 `0020-password-recovery.sql`（密码恢复迁移）保留旧密码、谷歌身份和原有邮件密文；新增凭据修订号、一次性请求、限流桶和账户邮件队列。恢复并不改写历史迁移，也不创建新用户或转移项目。回滚代码应配合已验证的数据备份恢复，不能删除新列或直接重写已应用迁移。

本机验证命令：

```sh
pnpm exec vitest run tests/password-recovery.test.ts tests/google-oidc.test.ts tests/mail-outbox.test.ts
pnpm test:e2e
```

第二条先构建网页与运行程序，再以项目局部 Chromium（浏览器）运行隔离用例。浏览器需先在项目目录安装：

```sh
PLAYWRIGHT_BROWSERS_PATH="$PWD/var/tools/playwright" pnpm exec playwright install chromium
```

自动化只使用每例独立临时数据库、媒体目录、本机邮件收件夹具及测试身份，不调用真实谷歌或外部发信服务。结果、失败轨迹、截图和日志保存在 `var/e2e/run-*`（端到端运行证据目录）；其中包含测试用登录凭据，不提交该私有目录。真实邮件投递和谷歌外部服务仍须独立授权验证。
