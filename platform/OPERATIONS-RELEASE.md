# 发布与恢复操作

适用日期：2026-10-26。当前代码可在隔离环境构建、运行和验收；真实对外收费运营还需要下述实际配置和联调。本文件不代表已部署或已取得任何服务资质。

## 1. 确定发布范围

- 可独立验收：账户与空间隔离、素材/项目/草稿、基础画布、版本/分享、额度记账、本机图片处理与视频裁剪。
- 模型生成、商户支付、第三方登录、邮件短信：先确认供应商合同、密钥权限、域名、运营配置和明确的最小联调预算；按代表业务验证费用与实际产物。协议夹具通过不代表真实服务可用。
- 正式税务开票、正式身份真实性核验、未核验的视频精准换脸/换装和小红书解析不纳入当前承诺。原站历史活动与模板未知不自动阻塞自有明确范围发布。
- 公开运营前确定运营主体、服务条款、素材传往第三方的告知、数据保留/删除规则和支持负责人；配置真实支持渠道。不得填入虚构主体、资质、送达或退款承诺。

## 2. 构建与检查

使用 `package.json`（依赖清单）约束的 Node.js（运行时）与 pnpm（包管理器），安装 FFmpeg/ffprobe（媒体处理工具）并加入进程搜索路径。

```sh
cd platform
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm build
pnpm verify:runtime
pnpm test:e2e
pnpm audit --prod
```

本仓库已下载的本机媒体工具位于 `var/tools/ffmpeg-9.0.2-macos-arm64/bin`（本机工具目录），不能复制为其他操作系统的生产依赖。浏览器验收脚本使用逐用例新数据库；浏览器、邮件和短信只访问回环夹具。生产启动探针也使用可销毁的新库，关闭外部服务。所有命令退出成功后，再核对本轮测试数量、业务断言和实际截图。

依赖锁定中，邮件组件升级至安全补丁 10.1.4；地址组件分别锁定 3.1.9、4.2.3；表格组件使用兼容其模块方式的标识符库 11.1.1。覆盖规则的依据及审计前后原件见本轮交付证据。后续上游升级时重新核查，不能将某日零公告视为永久安全。

## 3. 配置与启动

1. 为测试和正式环境分别准备数据库、媒体目录、密钥及商户配置。保持 SQLite（嵌入式数据库）和媒体目录在同一受控实例；不要将此部署方式视为已经支持跨机器共享写入或任意并发。
2. 首次管理员只在回环地址初始化，确认账户后再使用正式源站与反向代理公开访问。现有安装直接使用已有账户和原密钥。
3. 设置 `NODE_ENV=production`（生产模式）、`DEMO_MODE=false`（关闭演示），使用不同的随机签名与加密密钥，每项至少32字节。已有短密钥部署需要单独设计凭据迁移，不得直接替换密钥来通过校验。
4. `PUBLIC_ORIGIN`（公开源站）填写 `https://studio.example.com` 这类纯源站，不能有账户凭据、子路径、查询或片段。公网生产必须使用加密传输。
5. 分别启动服务端和执行器，并由部署环境负责重启、日志轮转与资源告警：

```sh
NODE_ENV=production pnpm start
NODE_ENV=production pnpm start:worker
```

`/api/v1/health`（接口健康地址）只证明接口和数据库响应，不能证明执行器、外部模型、真实送达或商户可用。启动后提交一个本机处理任务，检查真实输出文件、任务终态和额度释放；确认执行器进程日志。生产浏览器检查登录、图片/视频展示、画布保存和导出；内容安全策略不允许动态脚本执行，前端校验库已关闭动态编译。

## 4. 备份、升级与回滚

- 升级运行库之前先用 `pnpm backup`（在线备份命令）备份；新版本备份含逐文件摘要，发布前同时核验在途任务缓存，失败不会留下标记成功的目标目录。运行中的缓存若在快照后被清理，本次备份会明确失败；应等待任务稳定后重试。备份目标必须在媒体目录之外。
- 使用 `pnpm restore <备份目录> <新恢复目录>`（恢复命令）做真实恢复演练；只在新目录运行。源备份不会被修改，恢复副本中的已缓存任务路径会指向新目录。
- 缓存清单、归属或媒体异常会明确中断新备份的可恢复性核验及恢复，保留既有备份和运行原件核对。2026-10-19 历史记录中已知的范围不匹配缓存也适用此限制，不能在未检查的情况下宣称该旧副本通过新恢复规则。
- 旧格式没有完整摘要，无法证明密钥或预览自备份后未变；仍检查数据库、外键、原件摘要与文件大小。新格式摘要用于检出损坏，不是对抗能够同时篡改文件和清单者的签名认证。
- 迁移只能追加。部署前保留已验收代码与依赖锁文件；回滚优先将备份恢复到新目录并配对原版本和原密钥，不能让旧代码盲目连接已升级运行库。
- 备份包含密钥和私有媒体，需另存于受访问控制的备份介质。当前仓库脚本不等于已经配置了异地备份、恢复时限、监控或自动故障转移。
